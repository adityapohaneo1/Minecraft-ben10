LOADING SCREEN ART  (you supply the images, the game draws only the progress bar over them)

  boot.jpg   shown FIRST, before the start screen (company / studio logo screen)
  game.jpg   shown after you press PLAY, while sounds / models / city are loading

- Full-screen, landscape. 1920x1080 (16:9) is ideal. The image is scaled to cover the screen, so keep anything
  important away from the very edges. Leave the bottom ~15% fairly calm: the progress bar sits there.
- .jpg, .png, .webp or .jpeg all work (looked up in that order). If a file is missing, a dark green backdrop is used.
- Loading screens are silent on purpose.
